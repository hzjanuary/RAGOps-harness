# FinOps Proxy

Status: implemented by `US-011-core-proxy`.

## Purpose

The FinOps proxy is a local middleware for RAG applications that call OpenAI
Chat Completions. It forwards requests to OpenAI, reads the provider `usage`
block, calculates an estimated USD cost, and persists a local SQLite usage log.

## Runtime Contract

- Server binds to `0.0.0.0:8000`.
- `GET /health` returns a JSON health response.
- `POST /v1/chat/completions` accepts OpenAI Chat Completions JSON.
- The request must contain a non-empty string `model`.
- `stream: true` is rejected because US-011 requires a JSON response with a
  complete `usage` block before logging.
- The proxy forwards the request body to
  `https://api.openai.com/v1/chat/completions` with
  `Authorization: Bearer $OPENAI_API_KEY`.
- Successful responses are returned as OpenAI JSON after local logging
  succeeds.
- Client, configuration, upstream, parsing, and logging failures return a JSON
  error envelope.

Error envelope:

```json
{
  "error": {
    "code": "machine_readable_code",
    "message": "Human readable detail.",
    "request_id": "local UUID",
    "upstream_status": 400,
    "upstream_body": {}
  }
}
```

`upstream_status` and `upstream_body` are present only when OpenAI returned an
error response.

## Configuration

At startup, the proxy loads a local `.env` file before reading configuration.
Existing exported environment variables take precedence over values from
`.env`. The local `.env` file is secret material and must not be committed.

| Variable | Required | Default | Purpose |
| --- | --- | --- | --- |
| `OPENAI_API_KEY` | yes for proxy requests | none | OpenAI API key sent to the upstream API. |
| `RAGOPS_DB_PATH` | no | `ragops_harness.sqlite3` | SQLite database path for local FinOps logs. |

Missing `OPENAI_API_KEY` does not prevent boot. Requests return a JSON
configuration error until it is set and the process is restarted.

## Logging Contract

US-011 stores usage metadata only. Prompt and completion content are not
persisted by this story.

Table: `llm_request_logs`

| Column | Meaning |
| --- | --- |
| `request_id` | Local UUID generated by the proxy. |
| `created_at` | UTC timestamp for the proxy request. |
| `provider` | `openai` for US-011. |
| `endpoint` | Local API endpoint, currently `/v1/chat/completions`. |
| `model` | Model reported by OpenAI, falling back to request model. |
| `upstream_id` | OpenAI response `id` when present. |
| `prompt_tokens` | Input tokens from OpenAI usage. |
| `completion_tokens` | Output tokens from OpenAI usage. |
| `total_tokens` | Total tokens from OpenAI usage. |
| `cached_prompt_tokens` | Cached input tokens when reported. |
| `cost_usd` | Estimated text-token cost in USD. |
| `latency_ms` | Proxy-measured upstream round-trip and logging latency. |
| `status_code` | Upstream success status code. |
| `pricing_known` | `1` when the model matched a local pricing rule. |

## Cost Rules

Cost is calculated from OpenAI text-token usage:

```text
uncached_prompt_tokens * input_price
+ cached_prompt_tokens * cached_input_price
+ completion_tokens * output_price
```

Prices are stored as USD per 1M tokens. The first US-011 table covers common
OpenAI Chat Completions models including GPT-5.5, GPT-5.4, GPT-5.3/GPT-5.2,
GPT-5.1/GPT-5, GPT-4.1, GPT-4o, and o4-mini families. Unknown models are logged
with `cost_usd = 0.0` and `pricing_known = 0` so the proxy does not block new
model aliases.

Long-context premiums, regional uplifts, tool-call fees, audio/image token
pricing, and streaming usage aggregation are outside US-011.

## Non-Goals

- Multi-provider proxying.
- Streaming responses.
- Prompt or response body retention.
- Dashboard reads.
- CLI commands.
- Provider retry policy beyond returning a graceful JSON error.
